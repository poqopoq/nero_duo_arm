# OmniPicker 3 mesh source

Files in this directory are copied from the official AGIBOT OmniPicker URDF
package published in the product manual:

- Manual: https://www.agibot.com/DOCS/OS/omnipicker-manual
- URDF archive: https://cms-tos.agibot.com/legacy/agibot-en/en/file/ueditor/php/upload/file/20260804/1785825470874678.zip

The vendor package identifies its license as Apache-2.0. Mesh transforms and
inertial values are retained in `omnipicker3_gripper_macro.xacro`.
