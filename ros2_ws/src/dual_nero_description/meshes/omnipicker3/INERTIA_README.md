# OP3 P0 EC 惯性参数修正版

本包基于 OP3_P0_URDF_E，质量来自同级 `重量实测.xlsx`。质量单位为 kg，重心单位为 m，转动惯量单位为 kg·m²。

- 可通过网格检查的实体：按 URDF 视觉网格、网格缩放和视觉原点进行均匀密度体积分，再按实测质量定标。
- 网格无法可靠闭合、定向或通过不变性检查的实体：保留 E 版 CAD 重心，按 `实测质量 / 原 CAD 质量` 同比缩放惯量。
- `link14/link15` 与 `link24/link25` 的 53.2 g 组合质量按 E 版 CAD 质量比拆分。
- `link13/link23/link18/link28` 是闭环参考节点，无实体几何，不再包含惯性、视觉或碰撞元素。
- `inertial_correction.csv` 记录每根连杆的输入质量、最终参数、方法和网格检查结果。

本次仅修正惯性参数和包名/资源路径，不改变关节树、关节类型、关节轴、限位或运动学脚本。静态检查结果见 `validation_report.txt`。

回退到 CAD 的实体：base_link, link14, link16, link24, link26, link17, link27。
